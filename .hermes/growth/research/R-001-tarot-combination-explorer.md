# R-001 — Relationship-focused Tarot Combination Explorer

Status: RESEARCH

## Target query family

- tarot combination calculator
- Tower and Lovers tarot combination
- [card] + [card] tarot combination love

## User intent

A visitor has two cards and wants an interpretation in a specific context, especially love, without reading two isolated card-meaning pages.

## Evidence

The current SERP contains both curated combination explanations and interactive combination experiences. POPTarot publishes a Lovers + Tower combination page with contextual interpretation and a clarifying-card framing. Total Tarot offers an interactive Lovers + Tower experience with user-question input and free-credit mechanics.

Search volume: UNKNOWN.

## Existing competitors

- POPTarot — curated pair interpretation
- Total Tarot — interactive pair reading
- Other tarot meaning/combinations pages — exact competitive set requires a measured SERP export before build approval

## Why CSG may compete

CSG already has tarot deck, draw, interpretation, spreads, history, recommendations, and reflection-journal capabilities. A pair page can be a reusable tool surface rather than a static article.

## Proposed wedge

Start with 10–50 curated relationship-focused pairs. Each page should provide a useful interpretation, context selector, optional reversal state, and a clarifying-card interaction. Do not mass-publish all 3,003 unordered pairs initially.

## Conversion hypothesis

Free combination result → save/account → clarifying card or spread → relevant paid tarot product.

## Validation

Measure impressions, clicks, interaction completion, clarifier usage, account creation, and paid-product referral. Expand only where pages receive impressions and meaningful interaction.

## Unknowns

- Search volume and query diversity
- Actual CSG SERP position
- Production exposure of paid tarot products
- Whether users prefer pair pages or full spreads
