# R-007 — Embeddable Current Moon Phase Widget

Status: RESEARCH

## Opportunity

Offer a small, accurate, branded Moon-phase widget that other sites can embed, linking back to a CSG current-Moon page and free chart experience.

## User intent

Publishers, newsletters, spiritual communities, and personal sites want a current Moon-phase display they can embed without maintaining astronomical calculations.

## Evidence

Time.now offers a configurable embeddable Moon-phase widget with phase name, illumination, location/date, and next Full/New Moon options. Space.com also references embedded current-Moon widgets, showing the format is familiar to publishers.

Search volume: UNKNOWN. Referral demand: UNKNOWN.

## Competitor gap / CSG advantage

CSG already has Moon-phase calculation and deterministic astronomy. The test is not to win a broad Moon-phase SERP; it is to create a useful embeddable asset with tasteful attribution and a clear current-sky destination.

## Cheaper validation experiment

Create a static demo embed and documentation page using the existing Moon calculation, then distribute it to 20 relevant newsletter/community/site owners without building a full widget marketplace.

Baseline: zero CSG embed installs.
Target: 3 qualified installs or 5 written expressions of interest in 30 days.
Kill: fewer than 1 qualified install and no referral traffic after 30 days.

## Conversion

Embedded widget → referral click to CSG current Moon page → free chart or account → relevant tarot/astrology product.

## Scope hypothesis

One signed embed endpoint, one minimal responsive rendering, attribution link, versioned calculation contract, install documentation, and referral analytics. No manipulative link scheme.
